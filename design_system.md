# Design System: Burgee

## 1. Color System
Use only these colors, plus white/near-black for text contrast. Do not introduce any other hues.

| Token | Hex | Use for |
| :--- | :--- | :--- |
| `--champagne` | `#EACEAA` | Page background, light text on dark cards |
| `--whiskey-sour` | `#D39858` | Primary accent cards, buttons, highlight sections |
| `--honey-garlic` | `#85431E` | Secondary accent cards, hover states |
| `--burnt-coffee` | `#34150F` | Headline text, darkest card backgrounds, footer |
| `--white` | `#FFFFFF` | Body copy on dark backgrounds when extra contrast is needed |

## 2. Typography
- **Headlines:** bold, rounded, high-weight sans-serif (Bricolage Grotesque Black / Poppins ExtraBold / General Sans Bold). Uppercase for big statement headlines. Tight tracking, line-height 0.9–1.0 for stacked display type.
- **Body copy:** clean neutral sans-serif (Inter / Plus Jakarta Sans), regular/medium weight, line-height 1.5.
- **Scale:** section headlines 32–44px desktop / 24–28px mobile. Body copy 16–18px. Small labels/eyebrows 12–13px, uppercase, letter-spacing 0.05em.

## 3. Shape & Spacing
- **Max content width:** 1280px, centered, side padding 24px mobile / 60px desktop.
- **Card corner radius:** 28–32px on large cards, 20–24px on images inside cards, fully pill-shaped (`border-radius: 9999px`) on buttons.
- **Vertical rhythm:** 96–120px between major sections desktop, 56–64px mobile.
- **Shadows:** Soft, warm-toned drop shadows under floating product imagery — no harsh black shadows.

## 4. Tone of Voice
Confident, playful, appetite-driven. Short punchy phrases, sensory adjectives (smoky, juicy, bold, unforgettable), frequent exclamation marks on promo headlines — e.g. "Flavor That Makes History!", "Free Sides on Every Order!", "The Best Bite in Town!"
